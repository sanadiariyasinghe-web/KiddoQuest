## Demo checklist

- [ ] Apple TV simulator (or device) open on Home, demo family loaded (Settings → Load Demo Family).
- [ ] Calm Mode **off** for the demo (animations look better), sound on.
- [ ] Optional: pair a game controller (Simulator → I/O → Game Controller, or a real controller).
- [ ] Backup: a 60-second screen recording of both demos in case the simulator is slow.
- [ ] Rehearse to ≤ 7 minutes, leaving time for questions.
