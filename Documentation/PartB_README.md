**KiddoQuest TV**: a tvOS companion to the KiddoQuest iOS app (Part A).

| Part | Target | Platform | Folder |

Both apps live in the same `KiddoQuest.xcodeproj`. The tvOS target was added as a **separate target** with its own source folder. It does not compile, modify or depend on any Part A file, and the iOS target's settings were left unchanged.

## 2. Project overview

KiddoQuest TV is a family-friendly educational game for children aged 3–7. It takes the KiddoQuest learning worlds (Numbers, Letters, Shapes and Animals) to the living-room television. A friendly mascot, **Buddy**, guides the experience. Every screen is designed for the **Siri Remote** and the **tvOS focus engine** rather than for touch.

## 3. Problem

- Children's learning apps are almost always **single-player, single-screen** experiences on a phone or tablet. A parent watching over a shoulder is a spectator, not a participant.
- Siblings take turns by passing a small device around, so the "waiting" child disengages.
- Parents get little visibility into what their child is learning, or the visibility sits in a menu they rarely open.
- Many families already have a large shared screen (the TV) that is mostly used for passive video, including passive "educational" video.

## 4. Solution

KiddoQuest TV turns individual learning into a **shared living-room activity**:

- One big, readable screen that the whole family can see from the sofa.
- **Local multi-user profiles** ("Who's Playing?") and an **active-player switch** that needs only one press.
- **Family Challenge mode**: players take turns with one remote, and every correct answer adds to a shared family goal.
- A **Family Progress dashboard** that parents can read from across the room.
- Gentle, encouraging feedback with no lives, no timers and no penalties.

## 5. Target platform

- **tvOS 27** (Apple TV 4K / Apple TV HD), built with **SwiftUI** and the **Swift Observation** framework.
- Runs in the **Apple TV tvOS Simulator**, so no physical hardware is required.
- No backend, accounts, analytics or networking.

## 6. Target audience

- **Primary:** children aged 3–7.
- **Secondary:** parents (co-players and progress viewers), siblings, early-childhood educators.

## 8. tvOS-specific capabilities

- **Focus engine:** every interactive element is a SwiftUI `Button` (or a `.focusable()` panel) styled with a single shared focus treatment (`TVFocusEffect`).
- **`@FocusState` + `.defaultFocus`:** each screen chooses a sensible initial focus (PLAY on Home, the active player on "Who's Playing?", the first answer in a game, *Next Challenge* when a hunt completes).
- **`.focusSection()`:** rows of cards are focus sections, so a swipe in any direction always finds a target instead of getting stuck.
- **Menu / Back button:** a `NavigationStack` driven by an observable `TVRouter` means the remote's Back button always unwinds one level.
- **10-foot UI:** 1920 × 1080 layouts, 28–120 pt rounded typography, large cards and high-contrast white-on-night-sky colours.
- **Top Shelf & layered App Icon:** an original `AppIcon.brandassets` with a two-layer parallax image stack and Top Shelf images (generated by script; no third-party art).
- **Dynamic Top Shelf extension (`KiddoQuestTopShelf`):** a `TVTopShelfContentProvider` shows a "Play & Learn" row of game shortcuts. Selecting one opens the app straight into that game through a `kiddoquesttv://game/<kind>/<world>` deep link (`TVDeepLink`, handled with `onOpenURL`). If no player is chosen yet, "Who's Playing?" is shown first.
- **Game controllers (GameController framework):** in Family Challenge each child can hold their own controller. Controller 1 goes to the first player, controller 2 to the second, and so on (`TVControllerSeats`). Controllers show their player number, the light bar takes the child's avatar colour, and the turn banner shows 🎮 1 / 🎮 2. Pressing during someone else's turn gives a kind "Wait for your turn, Liam! It's Ava's go." with no penalty. The Siri Remote still works for everyone.
- **Adaptive levels:** each player has a level per choice game (2 → 3 → 4 answers). A 3-star round moves up (shown as "⬆️ Level up!" on Results), and a 1-star round moves down so a struggling child gets an easier game next time.
- **Every TV size:** all Apple TVs (HD and 4K) lay apps out in the same 1920 × 1080-point space. Each screen was rendered at that size
  (`KiddoQuest TV/Previews/TVResponsivePreviews.swift`). All content stays inside an 80-pt TV-safe margin, rows of cards fit
  the width even at the hardest level (4 answers), and long screens (Family Progress, Settings, Rewards) scroll with the remote.
- **Living-room audio:** an `.ambient` audio session, so KiddoQuest mixes politely with other audio.

## 9. Siri Remote / focus navigation

| Remote action | Result |

| Swipe / click pad ←→↑↓ | Moves focus between cards, answers and shapes |
| Click (Select) | Activates the focused card or answer |
| Back / Menu | Returns to the previous screen (Home → exits app) |

**Focus state design (`Components/TVFocusStyle.swift`):**

| Normal | Focused |
| --- | --- |
| Regular size | Scales up (1.04–1.12×, depending on element size) |
| Thin translucent border | **Thick 8 pt white border** |
| Subtle shadow | Coloured **glow** in the element's tint |
| Translucent card fill | Card fills with its category tint |
| — | Spring animation plus a soft synthesized focus "tick" (throttled) |

Focus is never shown by colour alone: the border thickness and size change as well. When **Reduce Motion** is on, focus changes use a short fade instead of a spring.

## 10. Multi-user / family experience

- **Local profiles:** Ava, Liam and Parent ship as a demo family. Each player has their own progress, points, stars and badges.
- **Active-player switching:** from PLAY, from the Learning World header chip, or from Settings → Player Profiles.
- **Family Challenge** (`Views/TVFamilyChallengeView.swift`, `ViewModels/TVFamilyChallengeViewModel.swift`):
  1. Choose who's playing (at least two players; everyone is selected by default).
  2. Pick a challenge: *Shape Squad* ("Can the family find 5 shapes together?"), *Counting Crew* or *Animal Parade*.
  3. A large **"AVA'S TURN"** banner shows whose turn it is. The scoreboard shows each **player's points**, the **family score** as stars filling up towards the goal, and **family challenges completed**.
  4. A correct answer gives that player +1 and the family +1 star, then the remote passes to the next player ("LIAM'S TURN"). A wrong answer gets a gentle "Almost! Try again!" and the same player tries again.
  5. When the goal is reached, a "The family did it! 🎉" celebration shows each player's points and any badges unlocked (e.g. 🌟 Family Learner). Results are saved for every participant.
- Every star earned in solo play is also added to the shared **Family Stars** jar.

> Multiplayer is local, same-room turn-taking with one remote. There is no online multiplayer, by design.

## 11. Game descriptions

The TV app has the **same seven games as the iOS app (Part A)**. Every game is a full game:

1. **Instructions:** a picture sentence children can follow without reading (e.g. 🐰 → 👆 → 🥕), two short steps for grown-ups, and a pre-focused **Let's Play!** button. The Learn → Play → Stars trail shows where the child is.
2. **Play:** an animated 👆 points at the right answer shortly after play starts and again after 8 seconds without an answer.
3. **Results:** stars, points, a new sticker, Buddy's dance, and Play Again / More Games / Home.

| # | Game | Worlds | Interaction on TV |
| --- | --- | --- | --- |
| 1 | **Counting Pop TV** | Numbers, Animals | "How many apples?" Large emoji objects pop in; focus one of four big numbers. Correct → sparkle burst, bounce, "Great job! +10", next round. Wrong → gentle shake, "Almost! Try again!", the tried option dims; no lives |
| 2 | **Tap-to-Match** (Numbers) / **Letter Match** (Letters) | Numbers, Letters | Count a group and choose its number, or choose the little letter that matches a capital. 5 shuffled rounds |
| 3 | **Tap-to-Reveal** | Shapes | "What colour should this sun be?" Four labelled swatches; the right one fills the outline with an animated colour reveal. 5 shuffled rounds |
| 4 | **Shape Hunt TV / Letter Hunt TV** | Shapes, Letters | "Find all the TRIANGLES!" Every item is focusable; *Found: 0 / 2 → 2 / 2*, then **Next Challenge**. 3 hunts |
| 5 | **Feed the Animals** | Animals | A hungry animal (🐰 🐶 🐵 🐱 🐭 🐼 🐝 🐔); choose the food it loves and it appears beside the animal with "Yum!". 5 shuffled rounds |
| 6 | **Animal Shadows** | Animals | A dark shadow of an animal; choose the matching animal and the shadow turns into the full-colour animal. 5 shuffled rounds |
| 7 | **Shape Sort** | Shapes | A shape plus Triangle / Circle / Square bins; choose the right bin and the shape drops in. 5 rounds, every shape at least once |
| ★ | **Family Challenge** | All | See §10 |

**Data flow:** Views read `TVAppStore` from the environment → `TVGamePlayView` shows the instructions, then the game (which owns an `@Observable` view model) → on finish, `TVGamePlayView` calls `store.recordSession(_:)` and `router.replaceTop(with: .results(...))`. The Results screen therefore replaces the game, so **Back** from Results returns to the category rather than to a finished game.

**Concurrency:** the target uses Swift's default MainActor isolation. Models and pure rules are explicitly `nonisolated`. Delayed transitions (auto-advance after a correct answer) use `.task(id:)`, so they are **cancelled automatically** if the player presses Back mid-celebration and can never navigate from a screen that has already gone.

## 13. Persistence

- `TVAppSnapshot` (players with their stickers, selected player, family score, settings including Calm Mode and the daily limit, last category) is JSON-encoded into **`UserDefaults`** after every change. Daily play time is kept separately in `UserDefaults` and resets each day.
- **Backward compatible:** profiles and settings saved by earlier versions still load (custom `init(from:)` with `decodeIfPresent`), and the retired `animalMatch` game kind maps to Feed the Animals.
- Why `UserDefaults`: tvOS does not guarantee persistent local file storage (the caches directory can be purged), but small `UserDefaults` data is kept. The snapshot is only a few kilobytes.
- **Safe defaults:** missing, corrupt or wrong-version data is ignored and the demo family loads. A stale selected-player ID is dropped. If no player is selected, games fall back to the first child profile.
- **Reset Progress** clears stars, scores, badges and the family score but keeps profiles. **Load Demo Family** restores the sample data for demonstrations.
- Tests use `TVInMemoryPersistence`, so they never touch real saved data.

## 15. Performance

- **No image or audio assets in the UI:** shapes, Buddy and stars are SwiftUI vector drawing, and sounds are synthesized once and cached as tiny PCM buffers. The only bitmaps are the App Icon and Top Shelf images (about 2.4 MB in total).
- **Limited continuous animation:** only Home and Results use the drifting background, with six shapes that animate transforms only. The drift stops on `onDisappear` and is disabled with Reduce Motion or Calm Mode. Buddy's idle bob is a single repeating offset.
- Feedback animations are one-shot. The sparkle burst uses 14 particles and replays without re-creating views.
- The audio engine starts lazily on the first sound, so there is no cost when sound is off.
- Small, bounded data; the game library uses eager rows because it only ever has seven cards.

# Part B Pitch

## 17. Value proposition

**KiddoQuest TV transforms children's learning from an individual mobile activity into a shared family learning experience on the television.**

- **Why the large screen matters:** everyone in the room can see the question, the answer and the celebration at the same time. Large objects to count and big shapes to find suit young children's developing fine-motor and visual skills better than a small touch target.
- **Why family participation matters:** young children learn best through joint engagement and talk with a caring adult or sibling. The turn-taking Family Challenge makes the parent a co-player, not a spectator, and gives siblings a reason to cheer each other on, since everyone fills the same family star jar.
- **Why tvOS is appropriate:** Apple TV is already the shared screen in many homes. It has a simple, child-safe remote and parental controls, and it connects naturally to the Apple ecosystem, where Part A (iOS) already lives.
- **Why focus navigation suits this audience:** "swipe to choose, click to answer" uses a few big, forgiving actions. There are no precise taps or drags, the focused item is always obvious, and every answer is a deliberate choice, which supports thinking before answering.
- **How it differs from a mobile/tablet app:** it is not a stretched iPad app. It uses 10-foot layouts, focus states instead of touch states, turn-based local multiplayer, a family score, a dashboard parents can read from the sofa, and remote-friendly redesigns of drag-based games.

## 18. Target market

- **Primary:** parents of children aged 3–7, especially households with an Apple TV and more than one child.
- **Secondary:** early-childhood educators (circle-time or classroom display on a TV), childcare centres, libraries and educational organisations.

Child-safety principles: no ads, no data selling, no in-game purchase prompts aimed at children, and the paywall sits behind a parent gate.

## 20. Go-to-market strategy

1. **Apple App Store / Apple TV ecosystem:** launch on the tvOS App Store with strong Top Shelf art and a preview video. Pitch for "Apps for Kids" / "Family Game Night" editorial features. Cross-promote from the iOS app (Part A users get a "Play it on your TV" prompt).
2. **Parenting communities:** soft launch in local and online parenting groups with free Premium trials in exchange for feedback.
3. **Parenting social media and educational creators:** partner with early-learning creators for short "family game night" videos showing parents and kids playing together, which is the moment that sells the product.
4. **Short-form demonstrations:** 15–30 second clips (Counting Pop celebration, "LIAM'S TURN!" hand-offs) on short-form video platforms.
5. **Schools and early-learning centres:** free classroom pilot licences, which produce testimonials and case studies, then a paid education tier.
6. **Acquiring early users:** a free tier that is genuinely useful, a referral reward (a free month for each family referred), a launch-week discount, and a seasonal "Family Learning Week" challenge event to drive repeat engagement and word of mouth.

## 21. Market potential

- **Shared learning:** co-play turns screen time into family time, which answers a common parental concern about solo screen use.
- **Family participation:** the parent becomes part of the game loop, which increases trust and willingness to pay.
- **Educational entertainment ("edutainment"):** kids' learning apps are an established, paying category (see Lingokids' and Sago Mini's subscription models), while interactive learning on the TV is still largely unserved.
- **Child engagement:** big visuals, Buddy and immediate positive feedback suit short attention spans.
- **Repeat usage:** per-player progress, stars, badges and recurring family challenges give reasons to come back daily and weekly.
- **Reward systems:** individual badges plus a shared family jar motivate both personal mastery and cooperation, not just competition.

## 22. Known limitations

- **Content depth:** games have 5 rounds (3 hunts for Shape Hunt). Adaptive levels apply to the five choice games, not to Counting Pop or Shape Hunt.
- **No profile editor on TV:** profiles are the demo family (Ava, Liam, Parent). Adding or renaming profiles is a future feature, best done from the companion iOS app because text entry with a remote is slow.
- **Local only:** progress lives in `UserDefaults` on one Apple TV, with no iCloud sync to the Part A app yet.
- **Controllers:** Family Challenge supports game controllers, but which controller pressed Select is inferred from the last controller that moved focus (tvOS does not report this for focus-engine presses). It has only been tested in the simulator; a real controller test is needed.
- **Audio:** sounds are simple synthesized tones with no voice-over narration; the app works fully without audio.
- **Localisation:** the TV app is English only (the iOS app has Sinhala and Tamil).
- **Part A data:** the TV target uses its own models and persistence. Part A's Core Data store is not shared.

## 24. How to build and run

**Requirements:** Xcode 27 or later with the **tvOS 27 SDK** and a **tvOS 27 Simulator runtime** (Xcode → Settings → Components, or `xcodebuild -downloadPlatform tvOS`).

1. Open `KiddoQuest.xcodeproj`.
2. Choose the **`KiddoQuest TV`** scheme.
3. Choose an Apple TV simulator (e.g. *Apple TV 4K (3rd generation)*).
4. **Run** (⌘R). In the Simulator, use the arrow keys / Return / Escape, or *I/O → Show Apple TV Remote*, to act as the Siri Remote.
5. **Test** (⌘U) runs the unit and UI tests.

To run **Part A**, choose the **`KiddoQuest`** scheme and an iPhone/iPad destination as before.

Command line:

```bash
xcodebuild -project KiddoQuest.xcodeproj -scheme "KiddoQuest TV" \
  -destination "platform=tvOS Simulator,name=Apple TV 4K (3rd generation)" test
```
