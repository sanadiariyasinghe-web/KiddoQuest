# KiddoQuest

**SE4041 – Mobile Application Design and Development · Assignment 02**

KiddoQuest is a learning-through-play app for kindergarten children (ages 3–7).
Children explore four learning islands (Numbers, Letters, Shapes and Animals), play short
picture-based games, collect stars and stickers, and find 3D objects in their room with AR.

| Part | Target | Platform | Documentation |
| --- | --- | --- | --- |
| Part A – Advanced iOS app | `KiddoQuest` | iOS / iPadOS 27 | [Part A README](Documentation/PartA_README.md) |
| Part B – tvOS prototype | `KiddoQuest TV` | tvOS 27 | [Part B README](Documentation/PartB_README.md) |

## Quick start

1. Open `KiddoQuest.xcodeproj` in Xcode 27 or later.
2. Pick the **KiddoQuest** scheme and an iPhone or iPad simulator (or a real device for AR).
3. Press **Run** (⌘R).
4. Press **Test** (⌘U) to run the unit and UI tests.
